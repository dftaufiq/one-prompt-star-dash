STAR DASH — a tiny neon browser game built by an AI agent from a single prompt: fly a spaceship with arrow keys, collect 20 stars to win, dodge asteroids with 3 lives. Open `game.html` in any browser to play. The X video in `star-dash-x-video.mp4` shows the prompt, the agent writing the code, and the game being played to a win.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
